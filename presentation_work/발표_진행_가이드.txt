Song Project 발표 진행 가이드

1. 표지 (20초)
- “아이디어가 곡이 되는 순간”이라는 한 문장으로 시작합니다.
- 작곡, 협업, 공유, 에어 악기가 하나의 작업 흐름이라는 점을 말합니다.

2. 발표 순서 (20초)
- 기술 설명보다 실제 사용 흐름과 기능 시연을 중심으로 보여준다고 안내합니다.

3. 프로젝트 개요 (50초)
- 전문 작곡 도구의 높은 진입장벽
- 메신저와 파일 전송으로 흩어지는 협업
- 이를 브라우저 작업실 하나로 해결했다는 흐름입니다.

4. 핵심 가치 (40초)
- 설치 없이 시작
- 실시간 공동 편집
- 스케치 단계부터 공유

5. 개발 환경 (40초)
- 프론트엔드, 오디오, 비전, 데이터, 실시간 기술을 간단히 소개합니다.
- 라이브러리 이름을 길게 설명하지 말고 각각 어떤 역할인지 말합니다.

6. 서비스 기능도 (40초)
- 작곡 화면을 중심으로 메인, 라이브러리, 커뮤니티, 협업이 연결됩니다.
- 영상 오버레이, 에어 악기, Song DNA는 작곡 경험을 확장합니다.

7. 작곡 화면 시연 (2분)
- 음 입력 → 재생 → 길이 수정 → 악기 음량 조절 → 반복 재생 순으로 시연합니다.
- 영상 오버레이를 넣고 영상에 맞춰 작업할 수 있음을 보여줍니다.

8. 음악 공유 시연 (1분)
- 업로드된 곡의 파형
- 좋아요와 마디 피드백
- 내 작업실로 가져오기
- 파트 모집 연결 순서로 보여줍니다.

9. 실시간 협업 시연 (1분 30초)
- 방 생성 → 파트 참여 → 채팅 → 동시 수정
- 두 브라우저 창을 준비하면 영상처럼 이해하기 쉽습니다.

10. 에어 악기 시연 (1분 30초)
- 기타, 드럼, 피아노 중 하나를 짧게 연주합니다.
- R 키로 녹화 시작, S 키로 종료 후 WebM 저장까지 보여줍니다.

11. 차별점 (50초)
- Song DNA
- 공유곡을 내 작업실로 가져오기
- 파트 모집 자동 연결
- 카메라 연주와 녹화

12. 시스템 구조 (40초)
- 클라이언트에서 즉시 반응
- 실시간 서버에서 협업 동기화
- Firebase/서버에서 프로젝트와 커뮤니티 데이터 저장

13. 기대효과 (30초)
- 작곡 진입장벽을 낮추고, 협업과 피드백을 빠르게 만든다고 정리합니다.

14. 마무리 (15초)
- “음악을 만드는 과정이 혼자가 아니도록”으로 끝냅니다.

권장 총 발표 시간: 약 11~12분
